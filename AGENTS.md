# Agent instructions

This repository is archived and is no longer maintained. Any remaining work is
limited to archival activities: keeping the archive notice accurate, removing
obsolete automation or status badges, and correcting archival documentation.

Do not add features, upgrade dependencies, fix known vulnerabilities, or
modernise the operating-system and application assumptions. Extensive testing
is not required for archival-only changes; validate documentation and
configuration edits proportionately.

If this repository is ever unarchived, update this file first. Remove the
archival restrictions and establish current maintenance, dependency, and
testing instructions before doing development work.

AI-assisted commits must include a disclosure trailer identifying the agent
harness and model, using the disclosure convention required by the active
harness. Do not remove or replace that trailer with an undisclosed commit.
